# AGENTS.md

## Thought & Progress Logging

Maintain a file named `thoughts_progress.md` to track the evolution of the project.

- **Append only:** Never regenerate or overwrite this file. Always append new content to the end.
- **When to log:** Append to this file whenever the user:
  - Proposes a new idea.
  - Cancels or rejects a previous idea.
  - Shares a new, important thought or crucial context ('good-to-know' info).
- **What to log:** Only record high-value information useful for the user or future AI LLMs. Do not log trivial or minor details.
- **No timestamps** in the logs.
